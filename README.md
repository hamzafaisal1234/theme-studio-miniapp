# Theme Studio Mini App (prototype)

هذه واجهة أولية مهيأة للعمل كتطبيق مصغّر داخل Telegram عبر Telegram Web Apps SDK.

## مهم قبل الاستخدام
لا يمكن فتح Mini App مباشرة من ملف محلي. يجب نشر `index.html` على عنوان HTTPS عام، ثم ربط هذا العنوان ببوت تيليجرام. الحزمة لا تحتوي على بوت جاهز أو رمز Bot Token، ولا تنشئ الاستضافة تلقائيًا.

## نشر مجاني عبر GitHub Pages من الهاتف
1. أنشئ مستودعًا جديدًا على GitHub، مثل `theme-studio-miniapp`.
2. ارفع `index.html` إلى جذر المستودع.
3. من Settings > Pages، فعّل النشر من الفرع `main` والمجلد `/ (root)`.
4. انتظر رابط HTTPS من GitHub Pages، مثل `https://USERNAME.github.io/theme-studio-miniapp/`.
5. افتح الرابط في Chrome للتأكد من ظهور الواجهة.

## ربطه ببوت تيليجرام
1. افتح `@BotFather` وأنشئ بوتًا باستخدام `/newbot` إذا لم يكن لديك بوت.
2. استخدم إعدادات Mini App / Main App المتاحة، أو `/setmenubutton` لإعداد زر Web App.
3. أدخل رابط HTTPS المنشور عندما يطلب منك ذلك. أسماء القوائم قد تختلف؛ اتبع ما يظهر في BotFather.
4. افتح البوت واضغط زر التطبيق المصغّر.

لا تشارك Bot Token ولا تضعه داخل `index.html`.

## ما يتضمنه النموذج
- واجهة عربية متجاوبة.
- رفع صورة وتحليل ألوانها محليًا في المتصفح.
- عناصر ألوان مستقلة ومعاينة.
- تحكم في شفافية فقاعات الرسائل والخلفية.
- حفظ إعدادات محلي وتصدير إعدادات JSON.
- استدعاء `Telegram.WebApp.ready()` و`expand()` عند الفتح داخل تيليجرام.

## ما لم يكتمل بعد
- لا يوجد backend أو بوت Telegram مبرمج ضمن هذه الحزمة.
- تصدير JSON هو إعدادات المشروع، وليس ملف ثيم تيليجرام قابلًا للتطبيق.
- حركة الخلفية محاكاة للمعاينة فقط.
- يلزم تطوير محرك تصدير متوافق واختباره داخل تطبيق تيليجرام الحقيقي.

الصور تُحلّل محليًا ولا تُرفع إلى خادم في هذه النسخة.
